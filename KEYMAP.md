## 文字輸入模式

| 按鍵 / 功能 | 說明 |
| :--- | :--- |
| `↑` / `↓` | 在字元選擇器中循環切換字元 |
| `←` / `→` | 在已輸入文字中左右移動游標 |
| `OK/Fire` | 輸入當前選中的字元 |
| `*` | 刪除游標前的字元 |
| `#` | 輸入空格 |
